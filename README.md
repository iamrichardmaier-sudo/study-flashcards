# study-flashcards

## ECON 381 — Midterm 1

126 term-and-definition cards from the ECON 381 study sheet, turned into an
iPhone flashcard app for [Scriptable](https://scriptable.app): a home-screen
widget plus a full review session using an accelerated three-button schedule
(Missed / Shaky / Confident). Each card has the simplest definition, extra
detail, connections to other cards, a real-world example, real numbers, a
worked example, and in most cases a graph.

- **Website:** <https://iamrichardmaier-sudo.github.io/study-flashcards/> (flashcards, the practice midterm as a guided multiple-choice drill, and interactive model dashboards). Sign in with your Wazn login to save.
- **Phone:** see [`scriptable/README.md`](scriptable/README.md). Paste `scriptable/econ381-review.js` into Scriptable. It syncs with the website.
- **The deck as data:** [`cards/econ381.json`](cards/econ381.json)
- **Source sheet:** `ECON381_Term_Definition_Cards_Study_Sheet.pdf`
- **Practice midterm:** `ECON381_Midterm1_Practice.pdf`
